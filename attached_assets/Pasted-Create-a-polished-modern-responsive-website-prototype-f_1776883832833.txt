Create a polished, modern, responsive website prototype for a product called InboxFlow.

InboxFlow is an email organization tool that helps busy professionals quickly find important emails without scrolling, searching, or missing key information. The product should feel clean, professional, efficient, and easy to use. The target user is a busy corporate employee who receives 40+ emails per day and depends on email for meetings, documents, coworkers, clients, and action items. The main pain point is that important emails get buried in a crowded inbox, causing missed replies, delayed work, and difficulty finding meeting links or shared files. Build the website to reflect that use case. :contentReference[oaicite:2]{index=2}

I will also upload supporting files. Read and use those files to guide the design, structure, copy, and interface decisions. Base the site closely on the attached materials, especially the storyboard, persona, OKRs, usability materials, and chosen prototype image. :contentReference[oaicite:3]{index=3}

Website requirements:

1. Overall goal
Build a clickable front-end website prototype for InboxFlow that looks like a realistic SaaS product website and app settings dashboard. It should showcase the product concept clearly and include the main settings page UI shown in my prototype.

2. Style and visual direction
- Clean modern SaaS design
- Professional but simple
- Rounded cards and panels
- Light background with subtle shadows
- Blue as the main accent color
- Use red, yellow/orange, and green for priority indicators
- Easy-to-read typography
- Plenty of white space
- Responsive for desktop first, but also works on tablet/mobile

3. Main pages/sections to include
Create these pages or sections:

A. Landing Page
Include:
- Product name: InboxFlow
- Clear headline
- Short subheading explaining the problem and solution
- CTA buttons like “Get Started” and “View Demo”
- Feature section
- How it works section
- Why InboxFlow section
- Optional testimonial or metrics section
- Footer

The landing page should explain that InboxFlow helps users:
- Automatically organize emails into folders
- Create custom filters and rules
- Tag emails by priority
- Find important emails faster
- Reduce missed action items

B. App Settings Dashboard
This should be the main focus and should match the uploaded prototype and wireframes as closely as possible while making it look polished and modern.

Include:
- Top title: InboxFlow Settings
- Connected email label, such as “Connected to Gmail”
- Sync Now button
- Return to Email button
- Folders section with table columns:
  - Folder Name
  - Color
  - Priority
  - Actions
- Example folder rows:
  - Meetings | Blue | High
  - Clients | Green | Medium
  - Internal | Purple | Low

- Filters & Rules section with table columns:
  - Filter Name
  - Keywords
  - Folder Name
  - Actions
- Example rows:
  - Meetings | zoom, calendar | Meetings
  - Clients | contract, proposal | Clients
  - Internal | update, FYI | Work or Internal depending on final consistency

- Priority Tags section
  - High, Medium, Low labels with color dots
  - Toggle switch for automatic sorting on/off
  - Save Changes button
  - Reset button

C. Right-side or modal editing panels
Include editable side panels or modals for:
1. Create/Edit Folder
   - Folder Name input
   - Color dropdown
   - Priority radio buttons: High, Medium, Low
   - Save Changes button

2. Create/Edit Filter
   - Filter Name input
   - Keywords input with comma-separated placeholder
   - Folder dropdown
   - Priority selector
   - Save Changes button

These forms should look similar to the uploaded chosen prototype image and wireframes, but improved with polished styling and consistent spacing. The storyboard and usability files show the user flow for opening settings, creating folders, setting filters, assigning priorities, and saving changes. Follow that structure. :contentReference[oaicite:4]{index=4}

4. Functional front-end behavior
Implement front-end interactivity only unless I later ask for backend support.
Add:
- Ability to open and close the create/edit folder panel
- Ability to open and close the create/edit filter panel
- Add new folders
- Add new filters
- Delete folders and filters
- Toggle automatic priority sorting on/off
- Save Changes and Reset buttons
- Store app state in localStorage so changes stay after refresh
- Show friendly empty states if rows are removed
- Form validation for required fields
- Clean hover states and transitions

5. Content and product messaging
Use copy that fits this product vision:
InboxFlow helps professionals spend less time searching their inbox and more time focusing on work. It keeps important messages organized and easy to retrieve using customizable folders, filters, and priority levels. The goal is to reduce search time, improve categorization accuracy, and reduce missed or late action items. The product is not meant to replace email providers and should not suggest that it writes replies, handles spam, or replaces Gmail/Outlook. :contentReference[oaicite:5]{index=5} :contentReference[oaicite:6]{index=6}
