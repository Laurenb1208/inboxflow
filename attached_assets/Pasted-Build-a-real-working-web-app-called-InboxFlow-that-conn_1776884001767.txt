Build a real working web app called InboxFlow that connects to a user’s email inbox and helps them organize and quickly find important emails.

Main goal:
InboxFlow should act as a companion email organization app. It should not replace Gmail or Outlook, but it should connect to a user’s inbox, read email data with permission, organize messages into custom folders/categories, apply filters based on keywords and context, assign priority levels, and make important emails easier to find.

Product concept:
The target user is a busy professional who gets a high volume of emails and struggles to find important messages like meeting invites, client emails, internal updates, shared documents, and action items. The app should reduce time spent searching for emails and make important emails easy to retrieve.

Tech stack:
Use a modern full-stack setup that runs well on Replit.
Preferred stack:
- Frontend: React
- Backend: Node.js with Express
- Database: PostgreSQL or SQLite if easier for Replit
- Auth: OAuth for Google first
- Styling: clean modern CSS or Tailwind
- State management: simple and clean
- Store sensitive keys in environment variables

Core requirement:
This should be a real app structure, not just a static prototype.

Build these features:

1. Authentication
- Add secure Sign in with Google using OAuth
- Let users connect their Gmail account
- Structure the code so Outlook support can be added later
- After login, store user profile and connection status
- Show whether Gmail is connected

2. Gmail integration
- Use the Gmail API
- With the user’s permission, read inbox email metadata and limited email content needed for sorting
- Pull messages such as subject, sender, snippet, timestamp, labels, thread id, and message id
- Do not permanently store unnecessary email body data unless needed
- Follow least-privilege access where possible

3. Dashboard
Create a polished dashboard for InboxFlow Settings based on this layout:
- Top title: InboxFlow Settings
- Connected to Gmail status
- Sync Now button
- Return to Email button
- Folders section
- Filters & Rules section
- Priority Tags section
- Save Changes and Reset buttons
- Right-side create/edit panels or modals for folders and filters

4. Folder management
Users should be able to:
- Create folders/categories
- Edit folder name
- Choose folder color
- Assign a default priority level
- Delete folders
- View folders in a table

Use starter sample folders:
- Meetings | Blue | High
- Clients | Green | Medium
- Internal | Purple | Low

5. Filters and rules
Users should be able to:
- Create filters with a filter name
- Add comma-separated keywords
- Assign each filter to a folder
- Assign a priority level
- Edit filters
- Delete filters

Use starter sample filters:
- Meetings | zoom, calendar | Meetings
- Clients | contract, proposal | Clients
- Internal | update, FYI | Internal

6. Priority system
Support three priority levels:
- High
- Medium
- Low

Add a toggle for automatic sorting by priority.
When enabled, the system should automatically classify emails by rules and/or simple logic.
Show priority with colored dots:
- High = red
- Medium = yellow/orange
- Low = green

7. Sorting logic
Implement working logic that:
- checks incoming synced emails against user-created filters
- uses keywords in subject/snippet/sender to determine category
- assigns matching emails to the appropriate InboxFlow folder/category
- assigns priority based on the rule
- if no rule matches, place the email in an uncategorized/default area

8. Email list view
Add a page or panel where users can see synced emails with:
- sender
- subject
- snippet
- date/time
- assigned folder
- assigned priority
- search bar
- filter by folder
- filter by priority

Users should be able to click an email to view more details.

9. Sync behavior
Add a working Sync Now button that:
- fetches recent emails from Gmail
- processes them through filters/rules
- updates the InboxFlow dashboard and email list
- shows loading, success, and error states

10. Data storage
Persist:
- user account
- connected provider
- folders
- filters
- priority settings
- synced email metadata and categorization results

Use a proper schema and keep code clean.

11. UX and design
Design should be:
- modern
- professional
- clean
- desktop-first but responsive
- light background
- blue primary accent
- rounded cards
- subtle shadows
- easy-to-read typography

12. Security and privacy
- Use environment variables for secrets
- Do not hardcode API keys
- Add comments for where Gmail OAuth credentials should be inserted
- Keep the app structured securely
- Include a short note in the UI explaining that users are granting permission for email organization only

13. Code quality
- Organize frontend and backend clearly
- Use reusable components
- Keep code readable
- Include basic validation
- Handle API errors gracefully
- Add comments where setup is required

14. Deliverables
Please generate:
- full project code
- frontend and backend
- database models/schema
- Gmail OAuth integration setup
- Gmail sync logic
- folder/filter/priority CRUD
- polished UI
- instructions for how to run the app in Replit
- clear setup steps for Gmail API credentials
- a sample .env.example file

15. Nice-to-have features if possible
- search emails by keyword

- analytics cards showing:
  - percent categorized

  - recent sync time
