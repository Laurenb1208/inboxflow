# inboxflow
Final Project for BAIS:3400 Digital Product Management.
InboxFlow is a simple web app that helps users organize and quickly find important emails.

## Overview
InboxFlow solves the problem of crowded inboxes by automatically organizing emails into folders, filters, and priority levels. This helps users spend less time searching and more time responding to important messages.

## Features
- Create and manage folders
- Set filters using keywords
- Assign priority levels (High, Medium, Low)
- Automatically sort emails
- Clean and easy-to-use dashboard

## Goal
The goal of InboxFlow is to make important emails easy to find, reduce missed tasks, and improve productivity.

## Tech
- Frontend: React / HTML / CSS
- Data stored locally (prototype)

## Status
This is a prototype project for design and development purposes.
